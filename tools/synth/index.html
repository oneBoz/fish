Quad Synth: synthetic drone images for YOLO

Renders random scenes of procedurally varied quadcopters with Three.js and writes YOLO labels from the projected geometry. Run python tools/synth/server.py and open this page through it so the files are saved.

Orange boxes are the labels that will be written. Five base models (X, H, plus, hex, racer) with random arms, hubs, rotors, guards, legs, colours and LEDs. IR-style frames are dark with bright LEDs and noise, like the fish's filtered camera.
